# Roadmap

Status: written (Session 0). Phases are scope boundaries, not dates. Dates are set when stories are estimated (Session 7).

## Phase 1 — MVP (validate the core loop)

**Goal**: prove the product hypothesis (`project-brief.md` §8).

Must have (P0): account; dog profile; dynamic questionnaire; goal selection; training path summary screen; daily agenda (3-day horizon); exercise detail; session completion + rating; optional notes; AI coaching response; next-day adaptation; freemium gate; framework admin panel with versioning.

Should have (P1, ship in MVP if cheap, otherwise early Phase 2): progress milestones; training streaks; web push reminders; weekly summary.

### Launch gates

| Gate | Source |
|---|---|
| Frameworks reviewed by at least one credentialed positive-reinforcement trainer | D-030 |
| US trademark search on "Biscuit" cleared | D-029 |
| Safety screening and escalation flow tested with excluded-case personas | D-004, R-03 |
| Engine test suite: fixture-driven tests for advancement, regression, priority, and biology gates pass | D-020 |
| Feedback flow measured under 30 seconds on a phone | D-012 |

## Phase 2 — Retention and depth

Progress analytics, weekly summaries, push notification strategy, milestone achievements, multiple dogs per account, CMS-style framework editor for trainers (D-024), additional skill frameworks, confidence score surfaced in plain language where useful.

## Phase 3 — Media-assisted coaching (photos)

Photo uploads for crate setup, training environment, equipment checks; environment analysis feeding the adaptive engine; first trainer-contributed frameworks.

## Phase 4 — Video coaching

Video uploads; AI coaching on handler technique (reward timing, leash handling, positioning); behavioral observation; training execution feedback. The second product identified in discovery ("AI dog training coach"), built on Phase 1's data.

## Later / unscheduled

Trainer marketplace, community features, family accounts, wearables, international expansion, reactivity and advanced behavior-modification tracks with professional-trainer involvement, trainer authoring platform.

---
**Why**: Phase order follows the discovery conclusion that the planner (Product 1) is the right place to start because it is simpler and easier to validate, while the coach (Product 2, media-assisted) is likely the more valuable business long term and depends on the data Phase 1 accumulates.
